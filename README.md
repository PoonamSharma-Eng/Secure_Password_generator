**Secure Password Generator**

I built this Python script to generate strong, randomized passwords. I specifically made sure it only uses "Safe Symbols" (@, #, $, etc.) that most websites actually allow, rather than weird characters that cause errors.

**What it does:**

It runs in a loop, so you can generate multiple passwords without restarting the script.

You can choose any length for the password.

It uses a mix of uppercase, lowercase, numbers, and safe symbols.

You can type **'exit'** whenever you want to stop the program.

**How to run:**

Make sure you have Python installed.

**Run the command:** python password_gen.py

Enter the length you want and get your password instantly.
